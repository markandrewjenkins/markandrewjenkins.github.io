VIX Swing Strategy

Live

A swing strategy trading volatility-linked ETFs (SVIX, UVIX) on signals driven by the VIX term structure. Prototyped in Pine Script, then rebuilt in Python as an event-driven backtester with walk-forward validation and Bayesian parameter optimization. Results publish to a self-contained HTML/JS dashboard, refreshed on a schedule via GitHub Actions. SVXY stands in for SVIX where longer history is needed.

NeonDeck

Work in progress

A handheld device for my own use, built on Waveshare's ESP32-S3 1.8-inch AMOLED touch board, with a custom interface inspired by the neon palette of 1980s synthwave (hence "NeonDeck"). It began as a Wi-Fi remote and now runs a small set of apps: a clock, battery monitor and three retro-style games that use the touchscreen, motion sensor and speaker. My first hardware project, written in C++ with Claude Code. Flight tracking and geocaching-style navigation are planned next.
